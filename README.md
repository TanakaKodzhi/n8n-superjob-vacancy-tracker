# 💼 Умный парсер вакансий с защитой от дублей

Сценарий автоматизации n8n для ежедневного мониторинга вакансий по стеку разработки через официальный REST API SuperJob с фильтрацией свежих публикаций, отсевом дубликатов между запусками и отправкой форматированного дайджеста в Telegram.

## Ключевые возможности

- **Автоматический сбор по расписанию:** Запуск по cron-таймеру (Schedule Trigger) каждый день в 19:00 по московскому времени.
- **Точечная фильтрация по времени:** Проверка даты публикации (`date_published >= now - 24h`) с отсевом устаревших предложений.
- **Защита от повторных отправок:** Нода `Remove Duplicates` в режиме `removeItemsSeenInPreviousExecutions` отслеживает уникальные идентификаторы вакансий (`id`) и предотвращает повторную публикацию уже отправленных позиций.
- **Безопасная агрегация и верстка:** Объединение записей через `Aggregate` с флагом `alwaysOutputData: true`, автоматическое экранирование HTML-символов (`&`, `<`, `>`) и форматирование вилок зарплат в Telegram-сообщении (с лимитом до 7 позиций в дайджесте).

## Быстрый старт и установка

### Предварительные требования
- Развернутый экземпляр n8n (self-hosted / Cloud).
- Ключ приложения SuperJob API (`X-Api-App-Id`), полученный в кабинете разработчика `api.superjob.ru`.
- Токен Telegram-бота от `@BotFather` и `chatId` целевого канала, чата или группы (бот должен обладать правами администратора на публикацию сообщений).

### Пошаговый запуск

**[Скачайте готовый JSON-шаблон](vacancies_monitoring_template.json)**

1. **Импорт сценария:**
   - Откройте интерфейс n8n.
   - Создайте новый воркфлоу, нажмите на меню с тремя точками в правом верхнем углу и выберите **Import from File**.
   - Загрузите файл `Vacancies_monitoring_template.json`.
2. **Настройка учетных данных и параметров:**
   - В ноде **HTTP Request**: укажите ваш ключ разработчика в заголовке `X-Api-App-Id`. При необходимости скорректируйте параметры `town` и `keywords[0][keys]`.
   - В ноде **Send a text message**: выберите настроенный Credential `Telegram account` и задайте параметр `chatId`.
   - В ноде **Schedule Trigger**: настройте желаемый час запуска (по умолчанию `19:00`).
3. **Активация:**
   - Переключите статус сценария в **Active** и сохраните изменения.

## Обработка краевых случаев

| Сценарий | Поведение системы | Результат |
| :--- | :--- | :--- |
| Отсутствие новых вакансий за 24 часа | Нода `Aggregate` с включенным параметром `alwaysOutputData: true` передает пустую структуру данных | Telegram-нода отправляет уведомление: «Свежих вакансий за последние 24 часа не найдено» без падения сценария |
| Наличие спецсимволов (`<`, `>`, `&`) в названии или ссылке | Функция `escapeHtml` внутри выражения Telegram-ноды экранирует управляющие символы | Валидный HTML-код сообщения, исключающий ошибку `Bad Request: can't parse entities` |
| Повторно опубликованные или не изменившиеся вакансии | Нода `Remove Duplicates` сверяет поле `id` с историей предыдущих выполнений | Дубликаты отсекаются из потока данных, в итоговую сводку попадают только уникальные новые элементы |
| Отсутствие явной вилки заработной платы в ответе API | Проверка значений `payment_from` и `payment_to` на `> 0` | Подстановка «по договорённости», «от X ₽», «до Y ₽» либо полного диапазона без вывода `null` или `0` |
